⚙️ Supabase bağlantısı

Supabase → Project Settings → API Keys / Data API bölümünden proje URL'sini ve publishable (veya anon) anahtarını gir. service_role / secret anahtarını asla girme.

Bu iki değer bu cihazda tutulur. Publishable/anon anahtarı herkese açık istemci anahtarıdır; veri erişimini RLS korur.

🔐 Giriş

Eski kayıtlar yalnızca bu cihazda bulunabilir. Aktarım aynı kayıtları yeniden eklememek için kimliklerini kontrol eder. Buluta aktarmadan önce doğru hesaba giriş yaptığından emin ol.
